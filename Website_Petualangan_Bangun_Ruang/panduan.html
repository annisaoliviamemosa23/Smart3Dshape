Gunakan Game Show lewat proyektor untuk lomba antarkelompok. Rekap nilai evaluasi ada di bawah. Kemajuan siswa tersimpan di peramban (browser) perangkat masing-masing.

📊 Rekap Nilai Evaluasi (perangkat ini)

Daftar ini berisi hasil evaluasi yang dikerjakan di perangkat ini. Untuk mengumpulkan nilai dari banyak perangkat sekaligus, sambungkan ke Google Sheets (lihat langkah di bawah).

🔗 Menyambungkan nilai evaluasi ke Google Sheets (opsional)
  1. Buat Google Sheets baru. Pilih menu Ekstensi → Apps Script.
  2. Hapus isi yang ada, lalu tempel kode di bawah ini dan simpan.
  3. Klik Terapkan → Deployment baru, pilih jenis Aplikasi web, atur akses ke Siapa saja, lalu klik Terapkan. Salin URL yang muncul.
  4. Buka file js/config.js, tempel URL itu pada window.SHEET_URL = "...", lalu unggah ulang website ke Netlify.
function doPost(e) {
  var sh = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  if (sh.getLastRow() === 0) sh.appendRow(['Waktu','Nama','Kelas','Absen','Nilai','Benar','Status','Durasi (menit)','Detail soal 1-10']);
  sh.appendRow([d.waktu, d.nama, d.kelas, d.absen, d.nilai, d.benar, d.tuntas, d.durasi_menit, "'" + d.detail]);
  return ContentService.createTextOutput('ok');
}

Kolom "Detail soal" berisi 10 angka (1 = benar, 0 = salah) sesuai urutan soal pada kisi-kisi: 1 (TP 5.2), 2 (5.1), 3 (5.3), 4 (5.4), 5 (5.6), 6 (5.3), 7 (5.5), 8 (5.4), 9 (5.3), 10 (5.6).
